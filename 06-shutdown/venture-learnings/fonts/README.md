# Fonts

The report script expects these font files in this folder (not bundled here for licensing reasons - both are free on Google Fonts):

- `CormorantGaramond-Light.ttf`, `CormorantGaramond-SemiBold.ttf`, `CormorantGaramond-Bold.ttf` - https://fonts.google.com/specimen/Cormorant+Garamond
- `Inter-Regular.ttf` - https://fonts.google.com/specimen/Inter
